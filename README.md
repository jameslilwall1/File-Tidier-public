# File Tidier — Releases

This repo hosts published installers for **File Tidier**, a one-off, safety-first Windows desktop cleanup tool. Scan a folder, preview every proposed move, rename, and delete before anything happens, execute your cleanup run with full undo at any time.

This is a **releases-only** repo — there's no source code here by design, so the app's auto-updater can check for and download new versions from a public feed without exposing the private source repository. The source lives at [jameslilwall1/File-Tidier](https://github.com/jameslilwall1/File-Tidier) (private).

## Download

Grab the latest installer from the [Releases page](https://github.com/jameslilwall1/File-Tidier-public/releases/latest).
